# AI in Cybersecurity: Threat Detection, Security Operations, and Emerging Risks

## Overview

This research project explores how Artificial Intelligence (AI) is transforming modern cybersecurity operations and reshaping both defensive and offensive cyber capabilities.

The report examines AI-powered threat detection, malware analysis, intrusion detection systems (IDS), security operations centers (SOC), cybersecurity frameworks, Zero Trust security, adversarial AI attacks, data poisoning, model drift, and the future of AI-driven cybersecurity.

The research also analyzes how organizations can leverage AI to improve security operations while addressing emerging risks associated with AI-enabled cyber threats.

## Key Takeaways

- AI is transforming cybersecurity operations through automation and intelligent threat detection.
- Security Operations Centers (SOCs) increasingly rely on AI to improve efficiency and incident response.
- Zero Trust architectures strengthen security through continuous verification and least-privilege access.
- Adversarial AI attacks, data poisoning, and model drift introduce new risks for AI-powered systems.
- Cybersecurity frameworks such as NIST CSF 2.0 provide structured approaches to managing cyber risk.
- Human expertise remains essential despite advances in AI-driven security technologies.
