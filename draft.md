# AI in Cybersecurity: Threat Detection, Security Operations, and Emerging Risks

## Status

Completed 

## Purpose

This file serves as the primary working draft for the research project.

The report examines the growing role of Artificial Intelligence (AI) in modern cybersecurity, including its applications in threat detection, malware analysis, security operations, risk management, and emerging cybersecurity challenges.

- Security Operations Centers (SOC)
- NIST Cybersecurity Framework (CSF 2.0)
- Zero Trust Security

- Data poisoning
- Model drift
- Cybersecurity frameworks
- Future of AI in cybersecurity

## Key Findings

- AI significantly improves threat detection and incident response capabilities.
- Security Operations Centers increasingly rely on AI-assisted workflows.
- Zero Trust and NIST CSF remain foundational cybersecurity models.
- Adversarial AI introduces new attack surfaces that require dedicated security controls.
- Continuous monitoring and governance are essential for maintaining trustworthy AI systems.
- Human expertise remains critical despite advances in security automation.
